本仓库未采用传统的应用程序配置文件系统，而是以 Shell 脚本加 Markdown 文档为核心的跨平台隐私环境配置方案，覆盖 macOS、Windows WSL2、Apple Container 三端，统一时区、语言区域、DNS、代理等运行时参数。

### 1. 采用的方法与工具
- 纯 Bash 脚本：switch-env-macos.sh、switch-env-wsl2.sh、switch-env-container.sh 作为统一的“一键切换”入口，通过命令行参数 us|jp|uk|sg|cn|check 选择目标区域。
- Markdown 操作手册：macos-host-privacy-setup.md、wsl2-sakuracat-privacy-setup.md、windows-host-privacy-setup.md、privacy-overview.md 详细记录各平台差异与验证步骤。
- 环境变量注入：通过写入 ~/.zshrc / ~/.bashrc 的 http_proxy / https_proxy / all_proxy / TZ / LANG / LC_ALL 实现应用层代理与时区控制。
- 系统级配置调用：macOS 使用 systemsetup、defaults write、networksetup；WSL2 使用 /etc/wsl.conf、/etc/resolv.conf、timedatectl；容器通过 docker run -e 或 --env-file 注入。

### 2. 核心文件与职责
- notes/qoderclicn/switch-env-macos.sh — macOS 宿主机一键切换（时区、语言、DNS、代理），支持 us/jp/uk/sg/cn/check。
- notes/qoderclicn/switch-env-wsl2.sh — WSL2 内运行，同时同步 Windows 宿主机的时区与 DNS。
- notes/qoderclicn/switch-env-container.sh — 基于 Docker/OrbStack/Colima 创建隔离 AI 编码环境，默认镜像 node:20-bookworm。
- notes/macos-host-privacy-setup.md — macOS 完整隐私清单，含 SakuraCat 代理 7897 + Cloudflare WARP DNS-only 架构说明、WebRTC 防护、Apple Container 隐私章节。
- notes/qoderclicn/ai-coding-security-privacy-guide.md — VS Code settings.json 权限白名单、.env 忽略规则等开发侧配置。

### 3. 架构与约定
- 三端一致约定：时区 America/New_York、DNS 1.1.1.1、区域 en_US，确保出口 IP 与时区匹配，避免指纹不一致。
- macOS 特殊路径：SakuraCat 走代理模式（端口 7897），不启用 TUN；WARP 仅做 DNS 加密，二者并行不冲突。
- WSL2 双端联动：脚本在 Linux 侧改 /etc/resolv.conf 并锁定，同时在 Windows 侧用 PowerShell 设置 Wi-Fi DNS 和时区。
- 容器网络差异：Apple Container 用 host.container.internal:7897 指向宿主机；Docker Desktop/OrbStack/Colima 改用 host.docker.internal。
- 可复用的 env 模板：文档建议创建 ~/.config/container/privacy.env，集中管理 TZ / LANG / 代理变量，供 --env-file 复用。

### 4. 开发者应遵循的规则
- 切换区域前先执行 ./switch-env-*.sh check 确认当前状态，避免误覆盖。
- macOS 上若已启用 WARP DNS-only 模式，不要再用脚本手动设置系统 DNS，以免冲突。
- 终端/CLI 必须显式设置 http_proxy / https_proxy / all_proxy，代理模式不会自动抓取命令行流量。
- 容器内 127.0.0.1 不等于宿主机，必须使用 host.container.internal 或 host.docker.internal。
- 所有变更均提供 cn 恢复命令，优先使用恢复而非手动回滚。
- .env、.env.*、credentials*、*.pem 等敏感文件应在 .gitignore 中排除，并在 VS Code settings.json 的 permissions.deny 中硬阻断读取。
