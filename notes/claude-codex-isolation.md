# Claude Code / Codex 防封禁隔离方案

在本地运行 Claude Code、Codex（OpenAI）等 AI 服务时，常因设备指纹、网络指纹或账户关联被封禁。本文整理一套完整的隔离方案，目标：**被封后能快速重开、且不影响宿主机**。

> 核心结论（太长不看）：
> - ❌ 不要重装 Win10 —— 清不掉硬件指纹，且「杀敌八百自损一千」。
> - ✅ 最稳妥的开发者配方：**干净的代理 IP + 虚拟机（或 Docker/WSL）+ 全新的注册资料（手机/邮箱/卡）**。

---

## 一、服务商如何识别你

| 指纹类型 | 示例 | 重装系统能否清除 |
| --- | --- | --- |
| 软件指纹 | 注册表残留、AppData 配置、浏览器 Cookie/缓存 | ✅ 可以 |
| 硬件指纹 | 网卡 MAC、主板序列号、CPU ID | ❌ 不可以 |
| 网络指纹 | 公网 IP 地址 | ❌ 不可以 |

**结论**：重置 Win10 只能清软件层，无法改变硬件与网络指纹，成本高且不彻底。

---

## 二、三大本地隔离方案

### 方案一：虚拟机 —— 最推荐的本地隔离方案

需要在本地运行 CLI 或 IDE 插件时，虚拟机是最好的选择。

- **原理**：VMware / VirtualBox / Windows 自带 Hyper-V 会虚拟出全新的硬件环境（新 MAC、新主板信息）。对服务商而言，这是一台完全陌生的新电脑。
- **操作**：在 Win10 内装一个 Ubuntu 或新的 Win10 虚拟机，在虚拟机内配代理并登录新账号。若再次被封，直接删除重开，完全不影响宿主机。
- **轻量替代**：只用命令行工具的话，可用 Docker 容器，隔离程度够用且更轻量（WSL2 的隔离能力有限，见第五章）。

### 方案二：指纹浏览器 + 纯净代理（针对网页端 / Web API）

主要通过浏览器或 Web 环境使用服务时适用。

- **原理**：无痕模式挡不住 Canvas / WebGL 等高级指纹。指纹浏览器（AdsPower、Hubstudio，或开源 Chromium 变种）可伪装操作系统、分辨率、字体、硬件加速等全部浏览器特征。
- **配合网络**：必须配全新干净 IP —— 不要用「万人骑」的免费 VPN 节点，最好是住宅 IP 或冷门 VPS。设备再新，IP 在黑名单里照样秒封。

### 方案三：云端开发环境（Cloud IDE）

既然本地环境已被污染，干脆不在本地跑。

- **方案**：GitHub Codespaces、Gitpod，或租一台便宜的海外 VPS。
- **优势**：完全独立的海外 IP 和硬件环境。用本地 VS Code 通过 Remote-SSH 连进去写代码，体验和本地几乎无差别，完美避开本地主机指纹问题。

## 三、防关联：账户维度的「四新」（极其重要）

很多时候新号被秒封，不是因为设备指纹，而是**账户信息关联**。必须做到：

1. **新网络** —— 绝对不能用之前被封时用过的同一代理节点 / IP。
2. **新手机号** —— 注册 Claude/OpenAI 通常需要接码，必须用全新的、未被拉黑的海外手机号（尽量避免已被滥用的接码平台虚拟号）。
3. **新支付方式** —— 绝不能用之前被封账号绑定过的信用卡；名字、账单地址最好也有所区分。
4. **新邮箱** —— 全新的 Gmail 或企业邮箱。

## 四、关于 WSL2 的澄清

> **Q：WSL2 创建 Ubuntu 时加参数能实现隔离吗？**
> **A：不可以。**

WSL2 架构是写死的：无论加什么命令或参数，Windows 都只会启动**唯一一个**轻量级虚拟机（Utility VM）。`wsl --install -d Ubuntu` 只是在这个共享虚拟机里解压了一个新的 Ubuntu 文件系统（类似新开一个容器），而**不是新建一台虚拟机**。

因此在 WSL2 中，无法通过加参数改变底层硬件指纹。要真正防封禁隔离，必须放弃 WSL2，改用真正的虚拟机（如下文的 Hyper-V）。

## 五、Hyper-V 管理器详细指南

Hyper-V 是微软官方的专业级虚拟机软件（类似 VMware）。每新建一台虚拟机都会生成全新的虚拟主板、UUID 和 MAC 地址，隔离效果极佳。

> ⚠️ **前提**：Hyper-V 管理器仅在 **Windows 10 专业版 / 企业版 / 教育版** 中提供。家庭版默认没有（虽可脚本强开，但建议直接用 VMware 或 VirtualBox）。

### 第一步：启用 Hyper-V 功能

1. `Win + S` 打开搜索，输入「启用或关闭 Windows 功能」并打开。
2. 在窗口中向下滚动找到 **Hyper-V**。
3. 勾选整个 Hyper-V 文件夹（确保「Hyper-V 管理工具」和「Hyper-V 平台」都被选中）。
4. 点击确定，等待配置完成后重启电脑。

### 第二步：下载 Ubuntu 镜像（ISO）

去 Ubuntu 官网下载安装镜像：

- 只需命令行写代码 → 推荐 **Ubuntu Server**（体积小、占用资源极少）。
- 需要图形界面 → 下载 **Ubuntu Desktop**。

### 第三步：在 Hyper-V 中创建虚拟机

1. 开始菜单搜索并打开 **Hyper-V 管理器**（Hyper-V Manager）。
2. 左侧面板点击你的电脑名称。
3. 右侧「操作」面板点击 **新建 → 虚拟机**。
4. 按向导配置：
    - **指定名称和位置**：起个名字，如 `Claude-Env-01`。
    - **指定代数**：强烈建议选 **第二代（Generation 2）**，性能更好，适合现代 Linux。
    - **分配内存**：建议 4096 MB（4GB），至少 2048 MB；可勾选「为此虚拟机使用动态内存」。
    - **配置网络**：下拉选择 **Default Switch**（通过宿主机 NAT 上网）。
    - **连接虚拟硬盘**：默认即可（如 20GB 或 30GB）。
    - **安装选项**：选「从可启动的映像文件安装」，浏览选中刚下载的 Ubuntu `.iso`。
    - 完成。

### 第四步：关闭安全启动（极其重要！）

选了「第二代」后，微软默认开启针对 Windows 的安全启动，会导致 Ubuntu 无法开机。

1. 在 Hyper-V 管理器列表中右键虚拟机 `Claude-Env-01` → **设置（Settings）**。
2. 左侧点击 **安全（Security）**。
3. 取消勾选 **启用安全启动（Enable Secure Boot）**。
   （或在模板里把 `Microsoft Windows` 改成 `Microsoft UEFI 证书颁发机构`，但直接取消勾选最省事。）
4. 确定。

### 第五步：开机并安装 Ubuntu

1. 双击列表中的虚拟机，弹出黑窗口。
2. 点击窗口上的 **启动（Start）**。
3. 像给真电脑装系统一样，跟着 Ubuntu 屏幕提示完成安装（设置用户名、密码等）。

### 防封禁核心玩法：快照与重置

环境搭好后，对付封禁的工作流：

1. **制作「纯净底包」**：Ubuntu 装好后配好代理，但**先不要登录 Claude 账号**。此时右键虚拟机 → **检查点（Checkpoint）**，相当于给干净系统拍快照。
2. **日常使用**：在虚拟机里正常登录账号写代码。
3. **被封禁后**：
    - **方法 A（最彻底，换全套指纹）**：直接删除虚拟机（右键 → 删除），然后重复「第三步」新建一台。新虚拟机有全新的硬件 UUID 和 MAC，绝不与上一个关联。
    - **方法 B（只换 MAC 地址）**：右键 → 还原到之前的「纯净检查点」；再进设置 → 网络适配器 → 高级功能，在 MAC 地址选项里选「静态」并随便改几个字符。开机后配合全新代理 IP 和新账号即可复活。

## 六、纯净住宅 IP VPS 推荐（绕过机房 IP 风控）

Claude、OpenAI 等对机房 IP 风控极严。需要寻找 VPS 圈里称为 **「双 ISP（Dual ISP）」「家宽 VPS」「住宅原生 IP」** 的小众服务商 —— 他们通过特殊渠道拿到了注册为**家庭宽带（ISP）**的 IP 段（AT&T、Comcast、Sprint 等）。在风控系统看来，这些就是真实家庭用户。

> 以下为 2026 年在开发者、跨境电商、AI 圈口碑较好的小众服务商，**仅作信息参考，购买前请自行核验最新情况**。

### 1. 专注美国 / 欧美双 ISP（主力推荐）

| 服务商 | 特点 | 优势 |
| --- | --- | --- |
| ** Lisahost（丽萨主机）** | 跨境/AI 圈出名，几乎是「双 ISP」代名词；专攻严格风控（TikTok、流媒体解锁、AI 接口） | IP 极度纯净；针对国内优化（AS9929、CN2），Surface SSH 连过去很丝滑 |
| ** DigiRTP** | 硬核美国家宽 VPS，可**直接选上游 ISP** | 可明确选 AT&T / Sprint / Cogent / CenturyLink 的 IP；提供 Linux 和 Windows |
| ** NovixLink** | 近期口碑不错的新锐商家，主打美国双 ISP 住宅 IP | 价格亲民；路由优秀（AS9929 + CMIN2 三网优化），兼顾「IP 干净」与「SSH 不卡」 |

| ** 六六云（666clouds）** | 老牌国人小众商家 | 提供美、英、日、韩的原生 IP 和双 ISP |

### 3. 亚太极速方案（嫌美国延迟高时）

希望 SSH 延迟在 50ms 以内，可考虑亚太家宽：

- ** ByteVirt** —— 稀缺的香港双 ISP 原生住宅 IP。
- ** Joyso（就速）** —— 台湾中华电信（HiNet）真实家庭宽带 VPS（PPPoE 拨号，每次重启换一个真实台湾家庭 IP），防封能力满级，但价格较贵。

### ⚠️ 购买与排坑指南（必读）

1. **认准关键词**：下单别买最便宜的普通套餐，必须确认套餐名带 **「双 ISP（Dual ISP）」「住宅 IP（Residential）」「家宽」** 字样。
2. **先月付，绝不年付**：再干净的 IP 段也可能被同网段恶意邻居连累。先买一个月跑 Claude Code 实测，确认不封且 SSH 不卡，再考虑长期。
3. **带宽妥协**：真正的家宽 / 双 ISP 机器带宽通常比机房小（50M–200M），但跑 CLI、写代码、调 API 完全够用。

### 终极操作步骤

买一台上述商家的 Linux VPS（推荐 **Ubuntu 22.04 / 24.04**）→ 在 Surface Pro 4 上打开 VS Code → 安装 **Remote-SSH** 插件 → 连接到 VPS → 在 VPS 终端里安装并运行 Claude Code。**性能拉满，绝对防封禁。**
