纯 Markdown 笔记仓库，按主题分层：
- `notes/` 根目录存放各平台隐私文档（macOS、Windows、iOS、WSL2）及 Computer Use 研究报告；`privacy-overview.md` 作为总索引，统一约束「America/New_York + 1.1.1.1 + en_US」三要素并串联子文档。
- `notes/qoderclicn/` 为互补材料，聚焦 Claude Code / Codex CLI 的账号安全与多区域环境切换，提供 `switch-env-macos.sh`、`switch-env-wsl2.sh`、`switch-env-container.sh` 三个 Bash 脚本，其端口已对齐本方案的 SakuraCat 7897，但 DNS/TUN 假设与本方案不同（见总览第七节差异说明）。
- 入口脚本 `macos-privacy.sh` 暴露 `apply [us|jp|uk|sg|cn]` / `verify` / `check` / `restore` 四个子命令，负责时区、区域、系统代理、终端代理变量与 IPv6 的一键落地与恢复。
- 依赖方向单向：`privacy-overview.md` → 各平台文档 → 脚本；qoderclicn 仅被引用为技术借鉴来源，不被本方案直接调用。
