本仓库为私人知识库与研究笔记集合，不包含任何传统意义上的构建系统。仓库由 Markdown 文档和 Bash 脚本组成，用于记录 Computer Use 桌面自动化能力评估以及跨平台隐私设置方案。

仓库中不存在以下构建相关元素：
- 无 Makefile、CMakeLists.txt、Cargo.toml、go.mod、package.json、pyproject.toml、setup.py 等构建配置文件
- 无 Dockerfile、docker-compose.yml（仅在 `switch-env-container.sh` 中动态生成临时 compose 文件）
- 无 CI/CD 流水线配置（.github/workflows、Jenkinsfile 等）
- 无版本发布流程或打包脚本
- 无编译、测试、部署相关的自动化流程

仓库中的脚本均为一次性运维工具：`macos-privacy.sh` 用于 macOS 隐私指纹一键配置，`switch-env-container.sh` 用于在容器中创建隔离的 AI 编码环境，其余均为说明性文档。这些脚本不具备可复用的构建语义，也不参与任何持续集成或制品管理流程。
