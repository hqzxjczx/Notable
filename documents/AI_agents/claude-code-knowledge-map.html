记忆与上下文6 项
CLAUDE.md
项目宪法，常驻上下文，每次会话自动加载。写稳定事实与约定。
memory 工具
Claude 的跨会话便签，由 Claude 自己维护，存放过程性发现。
plan 模式
动手前的批准提案：先探索、提方案，批准后才写文件。
tasks
会话内执行清单，用于拆解任务与跟踪进度。
@imports
@路径按需加载外部文件，控制常驻上下文体积。
位置体系
全局 / 项目 / 目录子树三级记忆文件，作用域递进。
自动化与配置6 项
Hooks
事件驱动自动化，配置在 settings.json。固定行为必须用它，不能指望记忆。
Slash Commands
用户显式触发的提示词，适合重复性手动工作流。
Skills
按需自动触发的能力包，Claude 根据描述决定何时加载。
MCP
外部能力接入层，工具命名 mcp__server__tool。
权限体系
allow / deny / ask 规则 + 四种权限模式（Shift+Tab 切换）。
settings 层级
策略 → 用户 → 项目 → 本地，逐级覆盖。
代理与工作流5 项
Subagents
独立上下文并行执行，隔离主线程、只回报结果。
后台任务
异步执行独立任务，完成时收到通知。
Plan Mode
先想清楚再动手——只读探索 + 方案审批。
Worktrees
同一仓库多工作目录并行，隔离实验与子代理。
多步工作流
plan → 分阶段 → 并行化 → 增量验证。
效率与质量5 项
提示词技巧
具体、给验收标准、给上下文而不是猜、小步迭代。
上下文管理
/compact /clear /context 控制占用；引用路径而非粘贴。
测试与评审
TDD + /review + 自动回归 hook。
Git 纪律
自动提交默认开，不 rewrite 历史，提交风格随仓库。
快捷键
Shift+Tab 权限模式、@ 文件、# 记忆、Ctrl+O 新会话。
